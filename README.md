# 💯 100 Days of Code – Python Pro Bootcamp

Repozytorium zawiera moje postępy z wyzwania **100 Days of Code**, opartego na kursie [The Complete Python Pro Bootcamp](https://www.udemy.com/course/100-days-of-code/) prowadzonym przez Angelę Yu.

## 🎯 Cel wyzwania

Nauka Pythona poprzez codzienne tworzenie projektów. Każdego dnia realizuję jeden projekt – od prostych skryptów po aplikacje webowe, automatyzacje, gry i analizę danych.

---

## 🛠️ Technologie i narzędzia

### 🧑‍💻 Programowanie
- Python 3.x
- Bash / Terminal
- Git, GitHub

### 🖥️ IDE / środowiska
- PyCharm
- Jupyter Notebook
- Google Colab

### 🌐 Web Development
- HTML5, CSS3, Bootstrap 4
- Flask (routing, templating, WTForms, Jinja2)
- REST API
- Autoryzacja i uwierzytelnianie
- Deployment: Heroku, GitHub Pages, Gunicorn

### 🎮 Gry i GUI
- Turtle
- Tkinter

### 🤖 Automatyzacja i scraping
- `requests`
- `BeautifulSoup`
- `Selenium WebDriver`

### 📊 Data Science i ML
- `pandas`
- `numpy`
- `matplotlib`
- `seaborn`
- `plotly`
- `scikit-learn`

### 💾 Bazy danych
- SQLite
- PostgreSQL
- SQLAlchemy ORM
